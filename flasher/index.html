Served from GitHub Pages — firmware updates automatically with every nightly build. No local server needed.

Tips: hold the BOOT button while plugging in the device if it is not detected. Use the install dialog's ⋮ menu and choose Erase device the first time you flash a board, or whenever switching between firmware variants.

Firmware is synced from the nightly release on GitHub, which is rebuilt automatically on every push to master.
